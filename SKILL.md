# 👑 AIDD Master Pack — Provisionador Autônomo de Projetos

Transforma uma ideia simples em linguagem natural em um **projeto de software ou fábrica de conteúdo 100% configurado, testado e orquestrado** em segundos.

## 🌟 O Que Esta Skill Executa Automaticamente:

1. **Zero Fricção de API Key (Harness Native Pass-Through):**
   - O projeto NÃO exige que o usuário cadastre chaves de API externas (`.env`).
   - Ele utiliza a inteligência nativa do Harness em que o usuário está (Claude Code, Antigravity, MimoCode, OpenCode, Cursor).
   - 90% das tarefas operam em determinismo mecânico local (Python + SQLite + Pandoc/Typst).

2. **Injeção do Tratado das 4 Camadas:**
   - **Camada 1 (Tela/UI):** Prefix Caching e Soberania Linguística (PT-BR).
   - **Camada 2 (Harness/Segurança):** Circuit Breakers (15 turnos máx, timeout) + Mesas ORCA.
   - **Camada 3 (LLM/Raciocínio):** Caveman Ultra Thinking + Roteamento Eficiente.
   - **Camada 4 (Tools/Determinismo):** Banco SQLite (`estado_projeto.db`) + Gates (`G_*.py`).

3. **Integração com a Skill `/implementacao`:**
   - Cada fase do projeto é executada no ciclo rigoroso: `impl` -> `test` -> `validate` -> `verify`.

4. **Mesas de Trabalho ORCA (Worktrees):**
   - Cria branches e pastas isoladas para cada especialista sem contaminar o chat do Mestre de Obras.

## 🛠️ Comandos da Skill:
* `/aidd-master-pack "descricao do projeto"` — Provisiona o projeto completo do zero.
* `/aidd-master-pack status` — Exibe a saúde das 4 camadas no projeto atual.

- **Padrão Impeccable Design System:** Todo frontend gerado pelo Master Pack utiliza paletas modernas (Dark Theme, Glassmorphism, Plus Jakarta Sans, micro-interações e responsividade impecável).


## 🚫 REGRA DE OURO DE DESIGN: ZERO EMOJIS EM INTERFACES (FIM DO AI SLOP)
- NUNCA use emojis (🚀, 🛒, 🛍️, 📱, ⭐, 🔥, 💎, ⚙, etc.) em botões, títulos, badges ou cards de interface.
- Use exclusivamente **Ícones Vetoriais SVG limpos** (estilo Lucide / Heroicons / Feather) ou badges tipográficas elegantes.
- Emojis empobrecem o design, deixam a interface com cara amadora/genérica de IA e quebram a consistência visual corporativa.
